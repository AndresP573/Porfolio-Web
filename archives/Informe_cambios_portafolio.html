Portfolio web: cambios en HTML, CSS y JavaScript

Resumen detallado de estructura, presentacion e interactividad.

12 de octubre de 2026

Resultado: una pagina estatica de portfolio con navegacion, proyectos, formulario y estilos responsive. Se agregaron ajustes de validacion, mejor estructura visual y una seccion de habilidades para completar la presentacion.

HTML: estructura y contenido

El documento sigue con lang="es", codificacion UTF-8 y viewport para mobile. Se renombro el titulo principal y se agrego una meta descripcion para mejorar la pagina.

  • Se mantuvo la navegacion con las secciones #sobre-mi, #proyectos y #contacto.
  • Se agrego una seccion de habilidades dentro de “Sobre mi” para dar mas contexto del perfil.
  • Se ampliaron los proyectos a tres tarjetas para que la pagina se vea mas completa.
  • Se añadieron tooltips sobre cada habilidad para explicar su tecnologia al pasar el cursor sobre ellas.
  • Se mantuvieron etiquetas y campos del formulario vinculados con for e IDs.
  • Se agrego novalidate para controlar la validacion con JavaScript y evitar mensajes nativos del navegador.
  • Se corrigieron textos visibles para dejar el contenido sin tildes, sin perder la legibilidad del proyecto.

CSS: diseno visual y adaptacion

La hoja de estilos se reforzo para dar una presentacion mas pulida y con mejor ritmo visual.

  • Se agrego un fondo suave con degradado y sombras ligeras para mejorar la apariencia general.
  • Se creo un layout de dos columnas para la seccion “Sobre mi” con una caja de habilidades.
  • Se anadieron efectos hover en proyectos y mejor espaciado para dispositivos pequenos.
  • Se ajustaron media queries para que la seccion de proyectos y la cuadricula de contenido se adapten mejor a pantallas estrechas.
  • Se mejoraron los estilos del boton y el estado del formulario para que se vean con mejor contraste.

JavaScript: validacion y mejor feedback

  • Se mantiene el año dinamico en el footer con new Date().getFullYear().
  • Se valida el nombre, correo y mensaje antes de aceptar el envio.
  • Se comprueba el formato del correo con una expresion regular sencilla.
  • Se muestra un mensaje claro si falta informacion y se mueve el foco al campo invalido.
  • Se limpia el estado del formulario al escribir en cualquiera de los campos.

Limite funcional: el envio real aun no se conecta a un backend ni a un servicio externo. La validacion actual sirve como feedback visual y de UX.

Verificacion realizada

  • Se comprobo la sintaxis de script.js con node --check.
  • Se revisaron los archivos HTML, CSS y JS para confirmar que los selectores y la estructura siguen coherent.
  • Se reviso que los comentarios del codigo se mantengan intactos, tal como se pidio.

Los cambios se registran en esta pagina de informe para dejar un seguimiento claro del proyecto.
